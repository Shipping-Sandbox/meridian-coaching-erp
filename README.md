# Meridian

The operating system for elite coaching institutions.

**Live:** https://coaching-erp.bolt.host

## What it is

Meridian is an ERP built for high-tier coaching institutes. It brings the day to day running of an institute into one refined platform, so admissions, teaching and money are not spread across spreadsheets and chat groups.

## What it covers

- **Admissions:** manage enquiries and enrolments
- **Academics:** keep batches, courses and student progress organised
- **Faculty:** manage the teaching staff
- **Finance:** track fees and institute finances
- **Analytics:** see how the institute is doing at a glance

## Who it is for

Coaching centres and test-prep institutes that want one system for the whole operation instead of a patchwork of tools.
